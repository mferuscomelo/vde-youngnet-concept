# Konzept

Ein bundesweiter Ort, an dem jedes Young-Net-Event in Sekunden auffindbar ist, Organisator:innen in Minuten veröffentlichen und jede Seite zur Mitgliedschaft führt.

## Probleme heute

- **Langsames Veröffentlichen:** E-Mail an die Geschäftsstelle, rund eine Woche Wartezeit.
- **Starre Branding-Regeln:** Gestaltungsvorgaben werden von Hand umgesetzt.
- **Falsche Zielgruppe:** Studierenden-Events erreichen Young Professionals und umgekehrt.
- **Event-Seite schwer nutzbar:** keine Filter, keine Suche, vergangene und kommende Events gemischt.
- **Zersplitterung:** eigene Websites je Bezirksverein, verstreute Hochschulgruppen.

## Was der Prototyp zeigt

| Idee | Seite |
|---|---|
| Event einreichen, mit einem Klick freigeben | `/de/einreichen`, `/de/organizer` |
| Filter nach Zielgruppe, Region, Fachgesellschaft | `/de/events` |
| Kalender-Abo für Outlook und Apple | `/de/events#abo` |
| Verzeichnis der Hochschulgruppen, Bezirksvereine, Fachgesellschaften | `/de/hochschulgruppen` u. a. |
| Weg zur Mitgliedschaft auf jeder Event-Seite | `/de/mitgliedschaft` |

Die ausführliche Fassung steht im Prototyp unter [Über das Konzept](https://mferuscomelo.github.io/vde-youngnet-concept/de/konzept).

## Woher die Inhalte stammen

- **Young-Professional-Termine:** Young-Net-Planungskalender (Stand 25.10.2026).
- **Verzeichnisse und Beiträge:** vde.com (Oktober 2026).
- **Zur Veranschaulichung ergänzt:** Hochschulgruppen-Events, Rückblicke, Stellen, Projekte, Statistiken.
- **Formulare** speichern nichts auf einem Server, nur im eigenen Browser.
